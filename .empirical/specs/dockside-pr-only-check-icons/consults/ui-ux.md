# UI/UX Advisory

Specialist: ui-ux

Verdict: advisory

## Findings

### U-001 — High — semantic ambiguity — ordinary checks

Ordinary completion checks look like approval and repeat on nearly every row.
Remove them rather than inventing another completion icon.

### U-002 — Medium — alignment — PR metadata

Put visible `#number` before the state icon and keep the icon as the final
right-edge element. This gives stable numeric scanning and a clear terminal
state cue.

### U-003 — Low — lost detail — completion

Quiet glyph/time and opening the thread provide sufficient detail without an
always-visible completion claim.
