## Design / maintainability

The release candidate keeps state projection, palettes, PR semantics, family ordering, and project ordering in small pure modules, with React components limited to interaction wiring. The final patch usefully centralizes child-status accessible presentation in ThreadStateGlyph and derives one childDisclosureLabel for both the control name and tooltip, preventing visual and assistive copy from drifting. Reusing semantic status icons and project headers for drag and keyboard sorting avoids extra chrome while preserving navigation ownership. Focused contract tests and live metrics align with the accepted decisions, with no material maintainability concern.
