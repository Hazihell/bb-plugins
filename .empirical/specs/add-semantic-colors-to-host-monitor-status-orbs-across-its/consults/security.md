# Security consultation

## Findings

No current security findings.

## Exploitability assessment

The accepted design closes the added tooltip and accessible-description trust boundary. Resource explanations are produced by a closed mapper over validated metric and severity values plus a bounded percentage; every other state uses fixed copy. Attacker-influenced `machine.alert.message` and `machine.error` are excluded, and explanation output is restricted to React text children or `textContent`. Consequently, malformed host telemetry cannot introduce executable markup through the new hover/focus surface or disclose raw operational errors through the visible UI, accessibility tree, or serialized DOM.

The rail-free neutral host containers do not create an authorization or data-integrity path. Visible state words remain authoritative alongside decorative semantic orbs, and disconnected precedence prevents retained critical or attention data from misrepresenting current connectivity.

## Recommendation

Implement the accepted design as written and retain the specified regression coverage for the closed mapper, bounded alert values, raw-field exclusion, and text-only rendering sinks. No further design change is required.
